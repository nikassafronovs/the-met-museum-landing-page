# The Met Museum Landing Page

A responsive landing page inspired by The Metropolitan Museum of Art, built with semantic HTML5, SCSS, and JavaScript, and bundled with Parcel.

## 🔗 Live Demo

Check out the live version of the project:
👉 [View Live Demo](https://nikassafronovs.github.io/the-met-museum-landing-page/)

## 🛠️ Built With

- **HTML5** – Semantic markup and page structure.
- **SCSS** – Modular styling, variables, mixins, and responsive layout.
- **JavaScript** – Interactive UI behavior and DOM handling.
- **Parcel** – Fast bundler and local development server.
- **Git & GitHub Pages** – Version control and hosting.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

1. **Clone the repository:**
git clone https://github.com/nikassafronovs/the-met-museum-landing-page.git
cd the-met-museum-landing-page
2. **Install dependencies:** `npm install` or `yarn install`

3. **Run the project locally:** `npm start` or `yarn start`

## Features

* **Editorial Landing Layout:** Structured multi-section museum showcase with clear visual hierarchy, typography, and balanced spacing.

* **Responsive Design:** Adapts cleanly across desktop, tablet, and mobile viewports using flexible layouts and media queries.

* **Modular SCSS Architecture:** Organizes styles into reusable partials, variables, mixins, and layout helpers (src/styles).

* **Interactive UI Elements:** Enhances user navigation and page interactivity with modular JavaScript (src/scripts).

* **Asset & Icon Organization:** Keeps icons, images, styles, and scripts cleanly separated inside src (icons, images, scripts, styles).

* **Production Bundling & Deployment:** Compiles assets with Parcel and publishes the static build to GitHub Pages.
